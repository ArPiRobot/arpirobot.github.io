Detailed Description

Camera object using the rpicam-vid program.

Can be used for Raspberry Pi camera modules. It may or may not work with other camera modules. It will not work with USB cameras.

This is a more reliable and customizable way to use RPi camera modules than LibcameraCamera. RpicamCamera allows setting extra controls.

When using this camera backend, extra options will be command line arguments to rpicam-vid

Important notes about rpicam camera

  • input format is not supported (raw will always be used)
